# General Guidelines

- Any .env.example updates to any modules need to be included in the top level .env.example as well
- OpenAPI Specification changes need to follow semver rules:
  - Breaking changes are 0.x.0 increments
  - Minor changes (additions but not changes or deletions) are 0.0.x increments
- Issues that are closed should be marked as such with a ✅ in the ROADMAP next to the issue
