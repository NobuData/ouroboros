Models

Route every kind of work to the model that earns it.

Each task kind resolves to a primary model with ordered fallbacks and escalation rules. Routes point at named registry aliases, never raw model ids — see the Model registry tab. The loop degrades gracefully when a provider stumbles — and never silently below the floor you set.
